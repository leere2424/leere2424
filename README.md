## 사람과 에이전트가 함께 일하는 방향을 지향하며, 이를 위한 경험을 쌓아가고 있습니다

경희대 생체의공학과 (2026.08 졸업예정) · AI 엔지니어를 준비하고 있습니다.

현재는 교수님 주도 프로젝트에 참여하여 다양한 직무를 대신하는 에이전트를
만들어보고 있습니다.

SK네트웍스 Family AI 캠프에서 RAG 기반 LLM HR 업무 보조 서비스를 기획부터 배포까지
직접 완성했습니다. LangGraph로 파이프라인을 설계하고, AWS 인프라 구축과 CI/CD
자동배포까지 진행하며 서비스가 실제로 운영되기까지의 전 과정을 다뤘습니다.

경희대 AI 연구실에서는 학부연구생으로 1년 6개월간 활동하며 딥러닝 전체 흐름
(데이터 전처리 → 모델 학습 → 평가)을 경험했고, 의료 영상 데이터 처리와
sLLM 파인튜닝(QLoRA)까지 진행했습니다.

### 🔧 Stack
LangChain · LangGraph · Pinecone · SQLite · EXAONE(QLoRA) · AWS(VPC/EC2/SSM/S3) · GitHub Actions
